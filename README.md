# API用量统计 — SillyTavern 扩展

用于记录和查看 DeepSeek 及兼容接口的调用数据，包括 Token、费用、缓存命中、响应表现、趋势预测与钱包余额。

## 功能

### 用量概览

查看余额、累计消费、总 Token、缓存命中、未命中、输出、平均每轮用量与费用、近两年的 Token 热力图，以及按对话汇总的轮次、费用和命中率。

### 用量统计

按时间、模型、对话、接入类型和 API 密钥筛选，查看消费金额、请求次数、Token、模型汇总和趋势图表，比较不同模型、时段与对话的用量和成本。

### 历史记录

浏览每次调用的模型、输入与输出 Token、耗时、速率、费用和缓存占比，点击“详情”后在电脑端右侧或手机端下部悬浮窗口查看请求与响应详情，也可选择新旧记录对比缓存断点。

### 趋势预测

以单个对话为单位，完整展示历史输入、输出、缓存命中率与实际成本趋势，并在上下文压缩点后重新拟合。支持 5/10/20/50/100 轮预测视界、自动测算或回退命中率、按历史压缩节奏预测下次压缩、余额与上下文可撑轮数，以及按输入输出比、每 1k 输出成本和缓存节省对比模型效率；能耗等级保留，最耗对话 Top 默认折叠在页面底部。

### 钱包

按接入地址管理多个钱包，查看余额、请求数、费用、密钥、模型和价格，并设置手工余额、官方余额校准、峰谷价格与模型价格。

### 导入、导出与云同步

支持导入旧版数据、备份和恢复已记录数据与钱包配置，也可通过 WebDAV 在多台设备间合并同步。校准密钥和聊天正文不会参与导出或云同步。

### 设置

调整颜色模式、历史范围、余额自动校准、默认峰谷、模型价格同步、调试和峰值圆点等选项。峰谷按 DeepSeek 官方规则计价：北京时间周一至周五（不含中国法定节假日）9:00-12:00、14:00-18:00 为高峰，其余时段（含周末和中国法定节假日全天）为空闲，调休上班的周末同样空闲。内置中国法定节假日数据覆盖 2024-2026，超出范围的年份可在设置中按日期补充“额外空闲日期”。

## 安装与更新

### 安装：

- 点击“安装扩展程序”，输入 `https://github.com/janmk1453/Api-Usage`（点击复制）
- 刷新后可见右下角魔法棒中的“API用量统计”入口
  支持导入旧版数据

### 更新：

- 在“关于 → 检查更新”中选择更新分支：`main`（默认，稳定）或 `dev`（测试）；点击“立即更新”会自动切换到所选分支并拉取最新提交，完成后刷新网页
- 也可以继续在管理扩展程序中点击更新，完成后手动刷新网页

## 快速开始

1. 完成安装并启用扩展。
2. 正常对话，扩展会自动记录调用数据。
3. 点击魔法棒中的“API用量统计”，从概览、统计、历史、预测和钱包页面查看数据。
4. 如需查询官方余额，请在对应钱包中填写校准密钥或直接设置手工余额。

## WebDAV 云同步

填写 HTTPS 地址、用户名、应用密码和子路径，即可手动合并同步历史与钱包配置。需要代理时，可填写可用的 CORS 代理地址。

匿名使用统计只上报随机匿名标识、浏览器环境分桶（浏览器名与主版本、系统、架构、语言、窄屏分桶、深色偏好、standalone、时区偏移）、8 个页面使用次数、打开次数、扩展版本与面板渲染耗时分桶；不含对话名称与内容、模型名、密钥、余额、费用与接口地址，服务端不记录 IP 地址，也不保存原始请求体。数据发送到部署者自建的 Cloudflare Worker 与其 D1 数据库，关闭开关后立即停止采集与上报，并可随时重置匿名标识。

扩展只能读取酒馆密钥条目的编号、备注和掩码末三位，用于区分请求来源，无法读取、保存或上传完整明文密钥。

模型价格同步会访问 models.dev，WebDAV 数据安全取决于用户选择的存储服务与网络环境。扩展不保证 models.dev 数据完全无遗漏，也不对其中出现或可能出现的商业化中转站构成推荐或合作关系。
